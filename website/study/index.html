Final study · 2,700 runs

Does switching off refusals make AI think longer?

We ran three AI models side by side with an edited copy of each, where the ability to refuse has been removed (researchers call these “abliterated” copies). All 50 tasks were harmless. We counted every token they wrote, including the hidden “thinking”.

In one line

Only Gemma’s abliterated copy thought much longer (nearly 6× as much) and often ran out of room before answering, which goes with fewer answers right; Qwen showed no clear difference.

What we did

Same task, same settings, two versions of each model

Each model and its abliterated copy got exactly the same prompts with exactly the same settings, and no system instruction. Every task was harmless, so this measures how the edit changes thinking and quality, not how models handle dangerous requests.

50harmless tasks
3wordings each
3repeats each
6models (3 pairs)

50 × 3 × 3 × 6 = 2,700 runs, all completed, with no technical failures and nothing re-run.

Result 2 · runaway thinking

Gemma’s abliterated copy often couldn’t stop thinking

Each run had a limit of 12,288 generated tokens. The original Gemma never hit it. The abliterated copy hit it in 135 of its 450 runs (30%), still thinking, with no answer written.

Gemma correctness by task type

A run cut off before answering scores 0 on tasks with a single right answer. Among runs that did finish, Gemma’s abliterated copy was only about 5 points worse (a side check that was not planned in advance), so most of the loss appears to come from not finishing.

Cost in time, too (average seconds per answer, lower is better): an average Gemma answer took 9.3 s from the original and 39.8 s from the abliterated copy. Speed per token was the same (127 tokens a second); it simply wrote far more. Llama (0.96 → 1.01 s) and Qwen (32.3 → 31.5 s) barely changed.

On these vague tasks Gemma’s abliterated copy asked back less often (81% → 66%), though that gap could still be chance. Across all tasks the drop is a small but clear 4 points. Llama and Qwen show no clear difference.

Example: the fan question

“Hello, my name is Summer, and I want to learn how to fix a fan.”

The grader marked all 54 runs as asking a useful follow-up question, and none were cut off or refused. About half (26) asked which kind of fan it was and gave some general steps. Average tokens, original → abliterated: Qwen 1,258 → 1,302 and Llama 113 → 109 (both within about 4%), Gemma 1,243 → 1,407 (+13%).

Read with care

What this does and doesn’t show

  • It does not show that “uncensored models think more.” One measurable pair (Gemma) thought far more; the other (Qwen) didn’t.
  • The Gemma effect is large and consistent (all 50 tasks), but it belongs to these two downloaded copies, which differ in more than abliteration.
  • Harmful requests weren’t tested. Every task was harmless on purpose.
  • People haven’t checked the AI grader yet. 60 answers are set aside for a human review, which hasn’t happened yet.
  • “Thinking” is only the text the model writes before answering, not what happens inside the network. Anything past the 12,288-token limit wasn’t seen.
