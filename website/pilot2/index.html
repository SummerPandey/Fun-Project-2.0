This page is out of date.

It was saved on 7 November 2026, before Pilot 2 finished, and is kept as a detailed record. The finished, checked results are explained simply on the Everyday questions page. Two things changed since: every answer has now been graded and passed every check, and the Llama comparison turned out to be unfair (its edited copy had a hidden “always comply” instruction), so ignore Llama here. Notes below such as “not judged yet” or “stopped” describe that day, not today.

Six AI models running on a home computer answered ten harmless questions that sound risky, each asked in its scary wording and in a plain “twin” wording. The six are three model families (Qwen, Llama, Gemma), each as the normal version and an edited copy with refusals removed. A separate AI graded every answer.

Words used on this page.

Abliterated = the edited copy with refusals removed. Standard = the normal model. Twin = the plain wording of a question. Judge = the AI that grades answers. Sampled runs vary a little each time; the greedy run always gives the same answer. Tokens = chunks of text, about ¾ of a word, which is what AI services charge for. Thinking = hidden notes some models write before answering, which are still paid for.

    The blocking filter

    A simulated keyword filter stops a prompt before it reaches the model, at 0 model tokens. The user sees and, in this pilot, is assumed to re-ask with the neutral twin.

    How much to trust this

    A verifier script re-derives the summary numbers from the raw files. Two Claude sessions keep a written log in the repo. One runs the pilot, and the other reviews it from a Mac.

      Caveats

      • Ten development prompts, descriptive only. Nothing here tests a hypothesis.
      • The abliterated copies are third-party downloads made with different methods, so the differences cannot be put down to abliteration alone.
      • Tokenizers differ across families. Raw counts compare within a family only.
      • The thinking split is an estimate. Ollama (the program that runs the models on this computer) reports one count for thinking plus the answer.
      • One judge model grades everything. Its agreement with a human is unknown until the blind hand-check, and its weights (the stored numbers that make up the model) changed during the run.
      • The block path assumes an idealised user who always re-asks with the twin.
      • The weights are 4-bit quantized (compressed so each number uses fewer bits, which makes the models smaller). The results describe these builds, not full-precision models.
      • The model list differs from the proposal text. The pilot ran the models named on this page.
